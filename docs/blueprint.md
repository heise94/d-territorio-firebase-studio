# **App Name**: Territory Manager Pro

## Core Features:

- Dashboard: User-friendly interface for managing territories, groups, houses, and schedules.
- User Invitation and Management: Allows pre-registration of users with an invitation token and management of roles.
- Territory Management: Create, read, update, and delete territories with details like number, name, type, map image, and last worked date.
- House Management: CRUD operations for houses, including owner, address, availability, and associated territories.
- Group Management: Management of preaching groups with details like name, description, superintendent, and auxiliary.
- AI-Powered Schedule Generation: AI tool for automatically generating monthly preaching schedules based on settings, availability, and group configurations.
- PWA Support: Progressive Web App functionality for offline access.

## Style Guidelines:

- Primary color: Emerald (#34D399) to reflect nature and growth.
- Background color: Light Gray (#F3F4F6) for a neutral and legible background.
- Accent color: Golden Yellow (#FBBF24) to highlight important elements and actions.
- Body and headline font: 'Inter' (sans-serif) for a modern, clean, and readable interface.
- Simple, modern icons for navigation and actions.
- Clean and functional layout with cards, buttons, tables, modals, badges, and inputs featuring rounded corners and subtle shadows.
- Subtle transitions and animations for a smooth user experience.
