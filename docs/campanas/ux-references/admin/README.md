# Referencias UX administrativas

Estas imágenes son referencias visuales aportadas por el propietario. La
arquitectura funcional se define en `ARQUITECTURA FUNCIONAL DEFINITIVA DEL
PANEL ADMINISTRATIVO`; las imágenes no definen permisos ni navegación.

| Archivo | Referencia |
| --- | --- |
| `01-super-admin-campanas.png` | Lista de campañas para super administrador |
| `02-nueva-campana.png` | Creación/configuración inicial de campaña |
| `03-mi-congregacion.png` | Revisión privada de participantes de congregación |
| `04-planificacion.png` | Planificador por bloque y participantes disponibles |
| `05-programa.png` | Revisión/publicación del programa |
| `06-solicitudes-cambio.png` | Gestión de solicitudes de cambio |
| `07-informacion-admin.png` | Información que verá el participante |
| `08-horarios-puntos.png` | Días, bloques y puntos de exhibidores |

Al implementar, reemplazar cualquier cruz, iglesia o dato ficticio de las
imágenes por elementos neutrales y por datos reales de la campaña.
